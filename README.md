### Project Description

DA Roast Bot is a humorous AI chatbot that answers users' questions with witty, sarcastic, and playful responses. It provides different roast levels, making normal conversations unnecessarily entertaining.

### The Problem (that doesn't exist)

Students have a serious problem: asking normal questions without getting roasted. Traditional chatbots are too polite and boring, creating an urgent need for unnecessary sarcasm.

### The Solution (that nobody asked for)

DA Roast Bot combines AI-powered answers with the personality of a sarcastic college friend. It answers the user's actual questions while adding an appropriate amount of humor and roast based on the selected mode.
